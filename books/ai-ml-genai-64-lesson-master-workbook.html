ARTHA AI/ML/GenAI Master Academy — 64-Lesson Workbook

Original learning guide, version 2.0. These lessons are authored study notes, not proof of runtime execution. Requires local model for interactive chat; offline notes/lab scripts work independently. Start with Python basics, basic algebra and a 64-bit Debian environment. Every exercise is intended to run locally or be adapted conceptually on an 8GB machine; modern LLM training is not feasible on that hardware.

AI Day 01 — Python and mathematical foundations

Module: Neural Networks & Deep Learning | Level: Foundation

Learning outcomes: vectors, matrices, shapes, dot product, mean and variance.

Core explanation: For a batch X with shape (N,D), weights W of shape (D,H) produce XW of shape (N,H).
